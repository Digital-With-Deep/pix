Add `@pix-ui/mcp`, an MCP (Model Context Protocol) server for AI coding tools such as Claude Code and Cursor. Run it with `npx @pix-ui/mcp`. It serves three tools over stdio, with no runtime dependencies and no network access: `list_components`, `get_component` (props table, docs page text and example source) and `suggest_component` (ranks components against a plain-language description of a UI).
