For non-React frameworks, `@pix-ui/css` exposes `pix-*` classes.

| Group | Classes |
| --- | --- |
| Buttons | `pix-btn` + `--filled` `--outline` `--ghost` `--secondary` `--destructive` `--sm` `--lg` |
| Badges | `pix-badge` + `--accent` `--success` `--warning` `--danger` `--info` `--outline` |
| Callouts | `pix-callout` + `--note` `--warn` `--truth` `--claim` |
| Surfaces | `pix-card` `pix-metric` `pix-table` `pix-tabs` `pix-tab` |
| Inputs | `pix-input` `pix-textarea` `pix-select` `pix-field` `pix-switch` |
| AI | `pix-response` `pix-thinking` `pix-prompt` `pix-claim` `pix-truth` `pix-fault` `pix-citation` |
