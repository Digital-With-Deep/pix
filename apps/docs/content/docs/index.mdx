PIX gives AI interfaces first-class primitives — a response that streams, a trace of what the model did, the sources it cited — next to the usual buttons, tables and forms.

- **`@pix-ui/react`** — React 18+ / Next.js components.
- **`@pix-ui/css`** — framework-agnostic `pix-*` classes for Vue, Svelte, Angular or plain HTML.
- **`@pix-ui/tokens`** — one token source for web and native.

Pick your framework under **Installation** to get started.
