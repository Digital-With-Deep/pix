# PIX Docs Site & Framework Examples Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a shadcn-style documentation site for PIX (Next.js + Fumadocs, static export → Firebase Hosting) with live component previews, API-accurate prop tables, per-framework install guides, and runnable Next.js/Vite/Angular starters.

**Architecture:** A new `apps/docs` Next.js App Router site (workspace member) consumes `@pix-ui/react` + `@pix-ui/css` via `workspace:*` and dogfoods PIX for its own chrome. Live previews come from an *example registry*: each demo is a real file whose exact source is extracted by a codegen step and shown in a copyable Code tab. Prop tables are generated by parsing the hand-written `.d.ts` contracts. Runnable starters live under `examples/` and install the published npm packages.

**Tech Stack:** Next.js (App Router, `output: "export"`), Fumadocs (`fumadocs-ui`, `fumadocs-core`, `fumadocs-mdx`), TypeScript, Node's built-in `node:test` + `react-dom/server` for tests (matching the repo's zero-dep test style), pnpm workspaces, Firebase Hosting, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-27-docs-site-and-framework-examples-design.md`

## Global Constraints

- Node `>=18`; package manager `pnpm@9.15.0` (root `packageManager` field; `apps/docs` is a workspace member).
- Packages live under `packages/*`; apps under `apps/*` (add `"apps/*"` to `pnpm-workspace.yaml`).
- `apps/docs` depends on `@pix-ui/react` and `@pix-ui/css` via `workspace:*`. The `examples/*` starters depend on the **published** npm versions and are **not** part of root `pnpm build`/`pnpm test`.
- Static export only: **no server-only route handlers** may remain in the exported app; search uses a build-time static index computed in the browser.
- Styling uses PIX tokens via CSS variables with a literal fallback: `var(--fg1, #1c1917)`. Never raw hex without the `var(--token, …)` wrapper.
- An AI claim (`--claim`) and ground truth (`--truth`) never share a colour.
- Identifiers, IDs, amounts, model and tool names are monospace.
- Text meets 4.5:1 contrast in light **and** dark; controls/focus rings 3:1; keyboard-reachable; reduced-motion respected.
- Sentence case, no exclamation marks, no emoji in product chrome.
- Initial component coverage is the curated 10: `Button`, `Badge`, `Callout`, `Alert`, `Tabs`, `Select`, `DataTable`, `MetricCard`, `AIResponse`, `PromptInput`.

## Review Focus

- **Dangling preview/props reference:** a `<Preview name="typo" />` or `<PropsTable component="Nope" />` in MDX must fail the build, not silently render empty. (Pinned in Task 8.)
- **Optional props & defaults in `.d.ts`:** an optional prop (`prop?:`) with a JSDoc `@default` and a union type must yield `required:false`, the captured default, and the full union string. (Pinned in Task 4.)
- **Dark-mode legibility:** the preview frame and Code tab must stay ≥4.5:1 in both themes; a demo must not hard-code light-only colours. (Pinned in Task 3.)
- **Static-export purity:** `next build` with `output:"export"` must succeed with no server route handler left behind (the scaffold's `/api/search` route is removed/replaced). (Pinned in Task 1.)
- **Registry name collision:** two example files resolving to the same registry key must fail codegen loudly. (Pinned in Task 2.)

`apps/docs/scripts/build-registry.mjs`:

```js
#!/usr/bin/env node
import { readdirSync, readFileSync, writeFileSync, mkdirSync } from "node:fs";
import { dirname, join, basename } from "node:path";
import { fileURLToPath } from "node:url";

const here = dirname(fileURLToPath(import.meta.url));
const examplesDir = join(here, "..", "registry", "examples");
const outDir = join(here, "..", "registry", "__generated__");

export function collectExamples() {
  const files = readdirSync(examplesDir);
  const entries = [];
  for (const f of files) {
    if (f.endsWith(".css.ts")) {
      const name = basename(f, ".css.ts");
      const mod = readFileSync(join(examplesDir, f), "utf8");
      // pull the exported `angular` template string for the code tab
      const m = /export const angular\s*=\s*`([\s\S]*?)`/.exec(mod);
      if (!m) throw new Error(`css example ${f} must export an \`angular\` template string`);
      entries.push({ name, lang: "html", importPath: `../examples/${f.replace(/\.ts$/, "")}`, source: m[1] });
    } else if (f.endsWith(".tsx")) {
      const name = basename(f, ".tsx");
      entries.push({
        name, lang: "tsx",
        importPath: `../examples/${basename(f, ".tsx")}`,
        source: readFileSync(join(examplesDir, f), "utf8"),
      });
    }
  }
  return entries.sort((a, b) => a.name.localeCompare(b.name));
}

export function buildRegistrySource(entries) {
  const seen = new Set();
  const imports = [];
  const records = [];
  entries.forEach((e, i) => {
    if (seen.has(e.name)) throw new Error(`duplicate registry name: ${e.name}`);
    seen.add(e.name);
    const id = `e${i}`;
    if (e.lang === "tsx") {
      imports.push(`import ${id} from "${e.importPath}";`);
      records.push(`  ${JSON.stringify(e.name)}: { name: ${JSON.stringify(e.name)}, lang: "tsx", Component: ${id}, source: ${JSON.stringify(e.source)} },`);
    } else {
      imports.push(`import * as ${id} from "${e.importPath}";`);
      records.push(`  ${JSON.stringify(e.name)}: { name: ${JSON.stringify(e.name)}, lang: "html", html: ${id}.html, source: ${JSON.stringify(e.source)} },`);
    }
  });
  return `// Generated by build-registry.mjs — do not edit.\nimport * as React from "react";\n${imports.join("\n")}\n\nexport const registry = {\n${records.join("\n")}\n} as const;\n\nexport type RegistryName = keyof typeof registry;\n`;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  mkdirSync(outDir, { recursive: true });
  const src = buildRegistrySource(collectExamples());
  writeFileSync(join(outDir, "index.ts"), src);
  console.log(`@pix-ui/docs: registry → ${collectExamples().length} examples`);
}
```

- [ ] **Step 5: Implement the parser**

`apps/docs/scripts/build-props.mjs`:

```js
#!/usr/bin/env node
import ts from "typescript";
import { readFileSync, writeFileSync, mkdirSync, existsSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const here = dirname(fileURLToPath(import.meta.url));
const componentsDir = join(here, "..", "..", "..", "packages", "react", "src", "components");
const outDir = join(here, "..", "registry", "__generated__");

// The curated 10 (Global Constraints); expand later.
const COMPONENTS = ["Button", "Badge", "Callout", "Alert", "Tabs", "Select", "DataTable", "MetricCard", "AIResponse", "PromptInput"];

export function parsePropsFromDts(file, interfaceName) {
  const source = ts.createSourceFile(file, readFileSync(file, "utf8"), ts.ScriptTarget.Latest, true);
  let rows = null;
  const visit = (node) => {
    if (ts.isInterfaceDeclaration(node) && node.name.text === interfaceName) {
      rows = node.members.filter(ts.isPropertySignature).map((m) => {
        const name = m.name.getText(source);
        const required = !m.questionToken;
        const type = m.type ? m.type.getText(source) : "unknown";
        const jsdoc = ts.getJSDocCommentsAndTags(m)[0];
        const description = jsdoc && typeof jsdoc.comment === "string" ? jsdoc.comment.trim() : null;
        const defTag = ts.getAllJSDocTags(m, (t) => t.tagName?.getText(source) === "default")[0];
        const def = defTag && typeof defTag.comment === "string" ? defTag.comment.trim() : null;
        return { name, type, required, default: def, description };
      });
    }
    ts.forEachChild(node, visit);
  };
  visit(source);
  if (!rows) throw new Error(`interface ${interfaceName} not found in ${file}`);
  return rows;
}

#!/usr/bin/env node
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

export function findDanglingRefs(files, previewNames, componentNames) {
  const errors = [];
  for (const { file, text } of files) {
    for (const m of text.matchAll(/<Preview\s+name=["']([^"']+)["']/g)) {
      if (!previewNames.has(m[1])) errors.push(`${file}: unknown preview "${m[1]}"`);
    }
    for (const m of text.matchAll(/<PropsTable\s+component=["']([^"']+)["']/g)) {
      if (!componentNames.has(m[1])) errors.push(`${file}: unknown component "${m[1]}"`);
    }
  }
  return errors;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const here = dirname(fileURLToPath(import.meta.url));
  const root = join(here, "..");
  const registry = await import(join(root, "registry", "__generated__", "index.ts").replace(/\\/g, "/")).catch(() => null);
  const props = JSON.parse(readFileSync(join(root, "registry", "__generated__", "props.json"), "utf8"));
  const previewNames = new Set(Object.keys(registry?.registry ?? {}));
  const componentNames = new Set(Object.keys(props));
  const walk = (d) => readdirSync(d).flatMap((f) => { const p = join(d, f); return statSync(p).isDirectory() ? walk(p) : p.endsWith(".mdx") ? [p] : []; });
  const files = walk(join(root, "content", "docs")).map((f) => ({ file: f, text: readFileSync(f, "utf8") }));
  const errors = findDanglingRefs(files, previewNames, componentNames);
  if (errors.length) { console.error("Dangling references:\n" + errors.join("\n")); process.exit(1); }
  console.log(`@pix-ui/docs: refs OK (${files.length} mdx files)`);
}
```

### Task 11: CI workflow + Firebase deploy + deploy docs

**Files:**
- Create: `.github/workflows/docs.yml`
- Create: `docs/DEPLOY-DOCS.md`
- Modify: `README.md` (link the docs site + examples)

**Interfaces:**
- Produces: CI that builds packages → builds docs (codegen + `next build` + check-refs) → builds the Next.js and Vite starters → deploys `apps/docs/out` to Firebase Hosting on `main` (PR previews on PRs).

- [ ] **Step 1: Write the workflow**

`.github/workflows/docs.yml`:

```yaml
name: Docs

on:
  push:
    branches: [main]
  pull_request:

concurrency: ${{ github.workflow }}-${{ github.ref }}

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm build            # builds @pix-ui/* so docs can consume workspace styles
      - run: pnpm --filter docs test
      - run: pnpm --filter docs build
      - name: Build React example starters
        run: |
          for d in examples/nextjs examples/vite-react; do
            (cd "$d" && npm install && npm run build)
          done
      - uses: actions/upload-artifact@v4
        with: { name: docs-out, path: apps/docs/out }

  deploy:
    needs: build
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with: { name: docs-out, path: apps/docs/out }
      - uses: FirebaseExtended/action-hosting-deploy@v0
        with:
          repoToken: ${{ secrets.GITHUB_TOKEN }}
          firebaseServiceAccount: ${{ secrets.FIREBASE_SERVICE_ACCOUNT }}
          channelId: live
          entryPoint: apps/docs
```
