# PIX + Next.js starter

A minimal Next.js App Router app demonstrating `@pix-ui/react` (installed from npm) with a themed page and a dark-mode toggle.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Learn more

See the full component docs and API reference at [github.com/Digital-With-Deep/pix](https://github.com/Digital-With-Deep/pix).
