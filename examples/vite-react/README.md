# PIX + Vite + React starter

A minimal Vite + React app demonstrating `@pix-ui/react` (installed from npm) — a `MetricCard` and a filled `Button`.

## Run it

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (defaults to [http://localhost:5173](http://localhost:5173)).

## Build

```bash
npm run build
```

See the full component docs and API reference at [github.com/Digital-With-Deep/pix](https://github.com/Digital-With-Deep/pix).
